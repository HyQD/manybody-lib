# Generated Matthews CIDT and CISDT equations

These LaTeX fragments are generated by the dependency-free closed-shell
symbolic engine:

```console
# CISDT
conda run --no-capture-output -n scipy-1.18.0 \
  python symbolic_derivations/closed_shell/generate_matthews_cisdt.py \
  --method cisdt --section all \
  --output-dir symbolic_derivations/closed_shell/generated

# CIDT (remove every term containing a singles amplitude)
conda run --no-capture-output -n scipy-1.18.0 \
  python symbolic_derivations/closed_shell/generate_matthews_cisdt.py \
  --method cidt --section all \
  --output-dir symbolic_derivations/closed_shell/generated
```

The files contain the exact metric data, metric-resolved right sigma vectors,
unnormalized norms and 1-RDMs, and all independent nonzero 2-RDM blocks for
the Matthews closed-shell CIDT and CISDT manifolds.  The CIDT expressions are
obtained symbolically by removing every term containing a left or right
singles coefficient before rendering.  Left and right CI coefficients remain
algebraically independent.

The default method remains `cisdt`.

The triples sigma is displayed with unnormalized simultaneous-column
permutation sums.  The columns are `(a,i)`, `(b,j)`, and `(c,k)`.  The
presentation uses:

- `\widehat{\mathcal P}^{ab}_{ij}` for a two-column orbit;
- `\widehat{\mathcal P}^{c/ab}_{k/ij}` for the three cosets of a
  two-column stabilizer;
- `\widehat{\mathcal S}^{abc}_{ijk}` for the full six-element `S_3` orbit.

These are presentation operators, not normalized physical projectors.  Every
factored expression is re-expanded automatically and compared with the
canonical algebraic result before it is printed.  Pass `--expanded` to print
the complete canonical sigma components without these operators.

Canonical dummy indices such as `i0` and `a0` are retained internally.  The
LaTeX renderer substitutes conventional occupied labels `i,j,k,l,m,n` and
virtual labels `a,b,c,d,e,f` term by term while avoiding free-index
collisions.  Primed labels are used only when a term needs more than six
distinct indices in one orbital space.
